# ALDITalk-Helper
Ein Bot der es automatisiert Datenvolumen bei ALDITalk nachzubuchen anstatt es manuell per App zu machen.

# Requirements:
Python 3.14+\
`json5`\
`playwright`

# Anleitung:

 1. `pip install -r requirements.txt`
 2. `config.json5` konfigurieren
 3. Mit `py main.py` starten
