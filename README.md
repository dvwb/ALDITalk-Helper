# ALDITalk-Helper
Ein Bot der es automatisiert Datenvolumen bei ALDITalk nachzubuchen anstatt es manuell per App zu machen.

# Requirements:
Python 3.14+\
`json5`\
`playwright`\
`certifi` (Für Telegram Bot API)

# Anleitung:

 1. `pip install -r requirements.txt`
 2. `playwright install` im Verzeichnis ausführen (Damit die Browser funktionieren)
 3. `config.json5` konfigurieren
 4. Mit `py main.py` starten
